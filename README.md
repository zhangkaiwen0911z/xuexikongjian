# 🐼 学习空间（fnOS 应用）

粉红童趣风的儿童学习打卡应用，已打包为飞牛 fnOS 可直接安装的 **FPK** 安装包。

## 📦 安装方法（二选一）

> ⚠️ **v1.0.4 重要更新**：已按真实上架应用规范补齐 `service_port`、`os_min_version`、`wizard/install` 等字段，manifest 增加 `disable_authorization_path`，CGI 增加 stderr 抑制与硬编码路径，修复安装后无桌面图标/无法打开的问题。开发者：凌。

**方法一：应用中心手动安装（推荐）**
1. 打开飞牛 fnOS 桌面 → 应用中心
2. **先卸载旧版本**
3. 点击「手动安装」，选择对应你设备架构的包，安装向导中可自定义访问端口（默认 8768）：
   - **x86 设备**：`xuexikongjian-1.2.0-x86.fpk`
   - **ARM 设备**（如部分 ARM 架构 NAS）：`xuexikongjian-1.2.0-arm.fpk`
4. 选择存储卷，安装完成后桌面上出现「学习空间」图标

**方法二：命令行安装**
```bash
appcenter-cli install-fpk xuexikongjian-1.2.0-x86.fpk  # x86 设备
appcenter-cli start xuexikongjian
```

**文件校验**（安装前可核对，防止传输损坏）：
- `xuexikongjian-1.5.0-x86.fpk` MD5：`a127216577d18006d0ae530bfcf83b90`
- `xuexikongjian-1.5.0-arm.fpk` MD5：`a821ce0789d4d4517d7fcd7427911272`
- 若文件被微信/QQ 等传输改名（如带 `(1)` 后缀），请改回 `.fpk` 后缀再安装

## ⚠️ 版本说明

**v1.5.0 为回退版本**：放弃 1.3.x 的端口服务模式（需占用端口并依赖 nodejs 运行时），恢复到 1.2.1 的 CGI 访问模式——安装即用、无需端口、无需额外运行时，启用更稳定。功能不变（年级/题库/主题/服务端存储），并保留「访问权限」可在应用设置中自主选择。

## 🌐 访问方式

- **默认端口：8768**，安装时在向导「访问端口」步骤可自定义（1-65535）
- 安装后通过 `http://NAS-IP:端口/` 访问，桌面图标直接打开
- 依赖运行时会自动安装（nodejs_v22）
- 网页与数据接口由内置 Node 服务提供，数据仍保存在服务端

## ✅ 家长审核机制

- 孩子完成任务后为「**待审核**」状态，**积分暂不发放**
- 家长管理顶部「✅ 今日任务审核」可看到今日每项任务的状态（未完成/待审/已通过/已驳回）
- 点「✅ 通过」→ 积分发放（含语文全通过 +5）；点「✖ 驳回」→ 退回可重做
- 支持「一键全部通过」；**管理员账号可切换查看并审核其他家庭成员**的任务
- 页面与顶部圆点会显示待审数量，孩子端能看到「等待家长审核」

## 🤖 AI 出题（DeepSeek）

题库管理点「🤖 AI生成」：选年级 + 学科 + 关键词 + 数量（1-10）→ 自动生成并预览 → 一键加入题库。
需先在家长管理 → 设置填写 **DeepSeek API Key**（密钥保存在服务端，不会出现在浏览器）。

## 📚 题库批量导入导出（支持 Excel）

题库管理中每个「年级+类型」都支持：
- **📤 导出**：当前列表导出为 JSON 文件
- **📥 导入**：把导出的 JSON（或自制题库）导入，自动校验并跳过无效条目
- **⬇️ 格式模板**：下载该类型的填写模板（含示例与说明），照格式填好即可导入

## 💾 设置自动保存

- 年级 / 背景颜色等设置**即时保存**到服务端
- 页面关闭前用 sendBeacon **兜底保存**，不再丢失最后一次修改
- 顶部积分旁有**保存状态圆点**：绿=已保存 / 黄=保存中 / 红=保存失败自动重试
- 列表与编辑弹窗支持**鼠标滚轮滚动**并显示粉色滚动条

## 👥 多用户数据隔离

- 应用通过**统一网关**访问（`/app/xuexikongjian`），每个 NAS 用户登录后使用**独立的数据文件**（`data-<用户ID>.json`）
- 各自的学习进度、积分、题库、熊猫互不影响
- 旧版共享数据会自动迁移：每个用户首次打开时继承原共享数据作为自己的初始数据
- 访问权限仍可在应用设置中自主选择（仅管理员 / 所有用户）

## 💾 安装存储空间

安装时飞牛会询问**选择安装存储空间**（存储卷），可自主选择放到哪个盘/卷（不再强制系统分区）。数据、题库、进度随之存放在所选卷。

## 🔐 访问权限

飞牛「应用中心 → 应用设置 → 访问权限」中可**自主选择**：
- **仅管理员**：只有管理员账号能看到并使用
- **设备内所有用户**：NAS 上所有用户都能访问

（默认仅管理员，随时可切换，无需重新安装）

## 🔧 安装问题排查

**v1.0.4 修复内容（关键，针对 fnOS 1.2.0505）**：
1. **`platform` 改为 `x86`**：此前一直使用 `platform=all`，而所有已知可正常安装出图标的应用（含上游 surface-battery CGI 应用、应用商店全部应用）均使用 `x86`/`arm`，从未见过 `all`。这是三轮失败（1.0.0/1.0.1/1.0.2）的共同变量，已改为与真实应用一致
2. manifest 全面对齐已知可用 CGI 应用：`install_type=root`、`ctl_stop=true`、`os_min_version=1.2.0`、`checkport=false`、`disable_authorization_path=true`、`changelog`
3. 桌面入口改为 `xuexikongjian.main`（与 `desktop_applaunchname` 一致），`allUsers=false` + `control.accessPerm=readonly`（与上游 CGI 应用一致）
4. 补齐 `wizard/config`、`wizard/uninstall`、`wizard/upgrade`（与上游一致）
5. 移除 app.tgz 中空的 `server/` 目录（上游无此目录）
6. 保留：ui/ 顶层 + app.tgz 双布局、checksum=app.tgz 的 MD5、CGI stderr 抑制与硬编码路径

**v1.0.0 → v1.0.1 修复内容**：
1. manifest 补充 `service_port=0`、`os_min_version`、`disable_authorization_path=true`
2. 桌面入口 `app/ui/config` 补充 `protocol: http`
3. 新增 `wizard/install` 安装向导（与真实应用一致）
4. CGI 脚本：开头 `exec 2>/dev/null` 抑制 stderr 污染、硬编码安装路径（CGI 环境中 TRIM_* 变量不可用）
5. 开发者改为「凌」
